NAME

configuration

DESCRIPTION

antenna uses configuration files to control its behavior.

ANTENNA.YAML (main configuration)

port
(optional, default: 8000) localhost port for preview
host
(optional, default: localhost) host name for preview
htdocs
(optional, default: “.”) directory for generated HTML/RSS
generator
(optional, default: page.yaml) default page generator YAML
base_url
(optional) the address the site is published at, with no trailing slash. The feeds, the sitemap and the table of contents (.well-known/toc.opml) are made from it; without it the table of contents is not written
author
(optional) the site-wide author. A page’s generated Markdown (antenna page SOURCE OUTPUT.md) and the site’s own posts in the collection page get it when they have no author of their own; an author in the document wins, and harvested items never get it. antenna validate does not suggest an author for a file when this is set
descriptionMax
(optional, default: 300) the longest description antenna validate accepts before it suggests a shorter one; 0 turns that check off. A negative or non-numeric value is a configuration error (exit 78)
sequences
(optional) the paths that hold a sequence of pages or posts, so previous and next are derived for their members. A list of entries, each with path (required) and order (optional). A path ending in / is a directory: its members are the published Markdown files directly in it, other than index.md, in order name (the default, by file name), date (oldest first, by pubDate or datePublished) or date-desc. A path ending in .md is a list file: its members are the site-local links in its body to published Markdown, in document order, each once; it takes no order. The list file is not a member of its own sequence. A member’s previous and next are its neighbours in the sequence; the first has only a next and the last only a previous. A document in two sequences takes the first one listed. The previous and next are written to the HTML and to the generated Markdown copy of a page, never to your own Markdown file. A missing path, an unknown order, an order on a list file, an entry with no path or a path listed twice is a configuration error (exit 78); antenna validate warns about a path that is not there.
subsites
(optional) other Markdown sites on the same host, so this site’s table of contents can point at them. A list of objects, each with url (required: the sub-site’s root, an absolute http or https address with a host, no query or fragment) and title (optional label). generate writes one include outline per entry, after the pages, collections and posts, in the order listed, at url/.well-known/toc.opml. BonBon asks only the root of a host for a table of contents and follows an include to reach a sub-site, so a host with several sites lists them here in the root site’s antenna.yaml. Write the address as the sub-site’s own pages are published (same scheme and host). Nothing is fetched: generate does not check that a sub-site exists. A missing or relative url, a duplicate, or an entry that is not a list of objects is a configuration error (exit 78). A relative .md link in a page or post that points into a sub-site on this host (one whose url has a path and the same host as base_url) is written into the HTML as the sub-site’s .html page of the same name, for example /antenna/index.md becomes /antenna/index.html, with no warning. A sub-site is taken to publish an .html page beside each .md page.
bonbon
(optional) the content of .well-known/bonbon.json, a mapping of keys to values. When it has at least one key, generate writes the file (a JSON object, keys sorted), and rewrites it only when it changes. BonBon reads three keys and only as strings: urlSearch, urlUpdateSocket and urlMirrorOf; any other key is written as given and ignored by BonBon today. A known key that is empty or not a string draws a warning, because BonBon keeps an empty one and a search then goes to a broken address: leave a key out instead of blanking it. With no bonbon setting antenna writes no file and never removes one, so a file you wrote by hand is safe; if you take the setting out, delete the file yourself. antenna runs no search or update service; see antenna help markdown-web
harvest
(optional) settings for the harvest verb. pause is the wait between two requests to one host, a duration such as 500ms or 2s (default 500ms; 0s turns it off). A value that is not a duration, or is negative, is a configuration error (exit 78). harvest: pause: 1s
collections
(required) list of collection objects

Each collection object: file : (required) path to the collection Markdown document

title
(optional, default: filename) display name
generator
(optional) per-collection page generator YAML override
mode
(optional) rendering mode: “aggregate” (default) or “page-index” “aggregate” feed-item cards from the items table (default), written to STEM_items.html “page-index” simple
    link list from the pages table, written to STEM.html
html
(optional) true or false: whether antenna writes HTML for the collection, its page and its posts. Default: true. false makes the collection Markdown-only: generate writes STEM_items.md (always, whatever markdownItems says), the RSS and the feed-list OPML and no HTML, and removes a STEM_items.html left by an earlier run. Post HTML from before is left (generate says how many files remain). A post made later is stored with its .md address as its link, and the sitemap lists it that way. A link to such a post or to the collection’s own files stays a .md link. The collection’s generator is not used (validate warns). html: false with markdownItems: false, or with mode: page-index, is a configuration error (exit 78). Readers that are not Markdown aware show a Markdown-only site as plain text, so use it for BonBon and cmarkbrowser.
markdownItems
(optional) true or false: whether generate writes STEM_items.md, the Markdown rendering of the collection’s items. Default: true for every collection except pages.md, whose items are the site’s own pages. false turns it off (the HTML, RSS and OPML are unchanged and a stale file is removed); true turns it on for pages.md.

Example antenna.yaml:

htdocs: htdocs port: 8000 base_url: https://example.org subsites: - url: https://example.org/opml title: opml - url: https://example.org/antenna bonbon: urlSearch: https://example.org/search collections: - file: index.md # aggregate (default) - file: links.md generator: links-page.yaml - file: pages.md mode: page-index # renders a simple link list
